5 Conclusion and Future Work

In this work a proof-of-concept method was shown which implemented chemicals for land-marking instead of using vision or EM waves. In pursuit of this idea, a mathematical framework was developed based on the diffusion equation. Constraints were introduced to aid in its simplification and a model was derived which quantifies the signal received by a sensor. Using the model, channel calculations were conducted to see the validity of using scent land-marking to convey information. The results have shown that when chemicals with suitable values (i.e., low diffusivity) where both chemical having similar diffusivity coefficient were chosen, it is possible for a mobile robot to detect the scent embedded to the environment and decode information about the previous robot which left the message minutes later.

Future-work will focus on increasing the information embedded to chemicals using different encoding methods and conduct field experiments.
