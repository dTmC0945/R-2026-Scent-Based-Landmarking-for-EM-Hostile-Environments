2.1 A Mathematical Model

To understand how the landmarks behave, a mathematical model is required. To model the medium, the following assumptions were made to derive an analytical model: the environment has no advection (i.e., 𝐯 = 0), The space in 𝑥𝑦-axis have no boundaries, The system has no sink/source (i.e., K = 0), The detector sensor has perfect absorption, and The diffusion constant. Under these conditions, the landmarks can be modeled using the diffusion equation  [23]:

ct = D (c𝑥𝑥 + c𝑦𝑦 + c𝑧𝑧) + K,

where c is the concentration of the mass (kgm−1), t is the mass transfer duration (s), D is the diffusion coefficient (cm2s−1), and K is the sink and/or the source. The solution for this equation can be derived using the following initial boundary conditions, known as the “thin-film solution” in the literature  [23]:

c (|x| ⊳ 0,|y| ⊳ 0,|z| ⊳ 0,t0) = 0, c (x = 0,y = 0,z = 0,t0) = M0δ(x)δ(y)δ(z), c (|x|→∞,|y|→∞,|z|→∞,t) = 0,

where M0 is the initial mass injected into the environment (kg), x is the Cartesian propagation dimension, t0 is the initial time (s) and δ(x) is the one-dimensional Dirac delta function. Under these conditions, the solution with an unbounded domain in x,y and a boundary at z = 0, can be expressed as follows:

C (x,y,z,t) = M (4πDx Dy Dz t ) 3 exp⁡ (− x2 4Dxt − y2 4Dyt − z2 4Dzt ) (1)

where kB is the Boltzmann constant1, P is pressure, T is temperature, mA,mB and dA,dB are the molecular masses and diameters of chemical A and B respectively. Eq. (1) quantifies the concentration value of the sample in a given time (t) and 3D space (x,y,z).
